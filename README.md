# OXY7O Platform Workflow

Reusable GitHub Actions workflows governed by `platform-governance@v1.1.0`.

Release target `v0.1.0` is a pilot for the `php-laravel` technology profile. The
repository uses layered global controls, PHP family behavior, Laravel profile
behavior, and typed optional extensions.

The initial scope performs CI and builds a verified `application-package`. It does
not deploy to development, staging, or production.
