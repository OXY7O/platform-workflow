# Dukungan

Gunakan GitHub Discussions untuk pertanyaan penggunaan dan ide. Gunakan issue untuk bug yang dapat direproduksi atau dokumentasi yang keliru. Gunakan private vulnerability reporting untuk masalah keamanan.

Repository ini disediakan sebagai komponen platform dan referensi teknis; ketersediaan kode tidak sama dengan jaminan dukungan operasional. Sertakan versi release, workflow SHA, log yang sudah disanitasi, dan langkah reproduksi saat meminta bantuan.
