# Kebijakan Keamanan

Jangan melaporkan kerentanan melalui issue, discussion, atau pull request publik. Gunakan fitur **Report a vulnerability** pada tab Security repository ini.

Sertakan komponen dan versi terdampak, langkah reproduksi minimal, dampak, dan mitigasi yang diketahui. Jangan sertakan credential atau data produksi. Maintainer akan melakukan triase, berkoordinasi mengenai perbaikan, dan mempublikasikan advisory bila diperlukan.

Hanya versi pada release terbaru yang menerima perbaikan reguler. Versi lama ditangani berdasarkan tingkat risiko dan kemampuan reproduksi.
