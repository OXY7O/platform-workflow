# Kontribusi

Terima kasih telah membantu meningkatkan standar platform OXY7O.

1. Buka issue yang menjelaskan masalah, dampak, dan hasil yang diharapkan.
2. Buat branch pendek dari `main` dan pertahankan satu tujuan kohesif.
3. Tambahkan atau perbarui test untuk setiap perubahan perilaku.
4. Jalankan seluruh validasi repository secara lokal.
5. Buka pull request; jangan menyertakan secret, data internal, atau credential.

Perubahan kontrak, permission, runner, dependency, dan security boundary memerlukan review maintainer. Dengan berkontribusi, Anda menyetujui bahwa kontribusi dilisensikan berdasarkan Apache License 2.0.
